# FamilyFit

Adaptive home-gym workout app for iPhone. A structured weekly training program
that reshapes each day's workout around a quick check-in (time available,
energy, sore areas).

## Use it

Open `index.html` in Safari on iPhone, then Share > Add to Home Screen.

Or enable GitHub Pages (Settings > Pages > Deploy from branch > main) and
open the published URL.

## Features

- Onboarding: equipment, training days, goal, session length (20/30/45/60 min)
- Adaptive daily workouts based on time, energy, and soreness
- Workout player with set tracking, load logging, and rest timers
- Exercise library with "How to" form-reference links
- History and simple stats, all stored locally in the browser

Built with Juno (Muse).
